# Tmux config

## Awesome Tmux Plugins
https://tmuxai.dev/tmux-plugins/

## Install plugins
Uisng [TPM](https://github.com/tmux-plugins/tpm)

**Note:** if running `tmux source ~/.tmux.conf` not install plugins, run install plugins script directly:

```bash
~/.tmux/plugins/tpm/tpm/scripts/install_plugins.sh
```
